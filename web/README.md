# Frontend (Vue)

Source: `web/` (Vue 3 + Vite). UI kit: `web/src/ui` (`@nlm/ui`).

See [docs/client-architecture.md](../docs/client-architecture.md) for:

- Cordis-lite modules (`web/src/runtime/`)
- Chat | Trajectory dual view
- Right dock (tabs + optional split)

## Develop

```bat
cd web
npm install
npm run dev
```

## Build

```bat
scripts\build_web.bat
```
